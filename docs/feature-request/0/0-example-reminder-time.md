# FR-0. Напоминание о поливе в выбранное время

> **Это пример.** Проект «Полив» выдуманный: Telegram-бот, который напоминает поливать комнатные растения. FR показывает, как выглядит заполненный документ. Удалите папку `0/`, когда заведёте свой первый FR.

**Статус: ГОТОВО, ред. 3 от 05.11.2026.** Ветка `feature/fr-0-reminder-time` от `dev`, смержена в `dev` 05.11.

**Откуда:** сообщение владельца 03.11. Текст дословно: [`assets/tz.md`](assets/tz.md).

**Связанные FR:** нет (первая задача).

**Не входит:** разное время для разных растений, напоминания чаще раза в день, выбор минут.

## 1. Решения

### 1.1 Решения владельца (04.11.2026)

| # | Вопрос | Решение |
|---|---|---|
| D1 | Шаг выбора времени: час или полчаса? | **Час, с 6:00 до 23:00.** Ночные часы не предлагаем |
| D2 | Часовой пояс: спрашивать или угадывать? | **Спрашиваем один раз**, при первом открытии «Времени напоминания». Пять кнопок самых частых поясов и «Другой» со списком |
| D3 | Что с теми, кто уже пользуется ботом? | **Ничего не меняем.** У них остаётся 10:00 по Москве, пока сами не выберут |
| D4 | «Видеть в статистике» это что? | **Одна строка в еженедельном отчёте:** сколько человек выбрали своё время, всего и за неделю |

### 1.2 Проверки до старта (сделаны по коду)

| Проверка | Итог |
|---|---|
| Можно ли слать напоминания в разное время | **Можно.** Сейчас одна задача по расписанию в 10:00 МСК (`tasks/reminders.py:14`). Меняем на ежечасный запуск с выборкой «у кого сейчас его час» |
| Хранится ли часовой пояс пользователя | **Нет.** Telegram его не отдаёт. Нужно новое поле (раздел 3) |

### 1.3 Решения по умолчанию (принимаем, если владелец не скажет иначе)

| # | Вопрос | По умолчанию |
|---|---|---|
| Q1 | Пользователь сменил время после сегодняшнего напоминания | Сегодня второе напоминание не шлём. Новое время действует с завтра |
| Q2 | Переход на летнее время в Калининграде и Новосибирске | В России переходов нет, храним смещение от UTC. Если появятся зарубежные пользователи, переделаем на названия поясов |
| Q3 | Кнопка «Другой» | Список из 11 российских поясов, от Калининграда до Камчатки |

## 2. Как должно работать

### 2.1 Настройки

В меню «Настройки» новая кнопка **«Время напоминания: 10:00»** (показывает текущее время). По нажатию:

1. Если пояс не выбран: «В каком ты часовом поясе?» и кнопки Москва, Калининград, Екатеринбург, Новосибирск, Владивосток, Другой.
2. Сетка часов 6:00…23:00, текущий час отмечен.
3. После выбора: «Готово! Буду напоминать в 19:00 по твоему времени».

### 2.2 Отправка

Задача запускается каждый час в :00 и выбирает тех, у кого сейчас наступил их час с учётом пояса и кому сегодня ещё не отправляли.

## 3. Изменения API и БД

**БД (миграция `007_reminder_time`):**
- `users`: + `reminder_hour` (smallint, 6..23, по умолчанию 10)
- `users`: + `utc_offset_min` (smallint, по умолчанию 180, то есть Москва)
- `users`: + `last_reminder_date` (date), защита от двойной отправки
- `users`: + `reminder_hour_changed_at` (timestamptz), для строки в отчёте (добавлено 05.11, см. I3)

**API:** не меняется, всё внутри бота.

## 4. Проверка и приёмка

- **Юнит-тесты:** выборка «у кого сейчас час» на границах суток (Калининград 23:00, Камчатка 6:00), Q1, отсутствие двойной отправки при повторном запуске задачи.
- **Живая проверка:** тестовый аккаунт в Telegram: выбрать пояс и час, дождаться напоминания (dev-команда `/fake_hour` сдвигает часы задачи).
- **Данные:** `select reminder_hour, utc_offset_min, last_reminder_date from users where id = …`
- **Документация:** `docs/ARCHITECTURE.md`, раздел «Напоминания».

## 5. Риски и открытые вопросы

- Ежечасная задача упала на час: эти пользователи не получат напоминание в тот день. Догонять не стали, это проще (см. I2).

## 6. Реализация: решения по ходу и отклонения (05.11.2026)

| # | Ситуация | Решение |
|---|---|---|
| I1 | Пользователь заблокировал бота | Помечаем `blocked_at` и больше не выбираем, чтобы ежечасная задача не спотыкалась об ошибки Telegram |
| I2 | Задача пропустила час (рестарт сервера) | Не догоняем. Записано в TODO как возможное улучшение |
| I3 | Строка в отчёте (D4) | «Своё время напоминания: 214 человек (+37 за неделю)». Новые за неделю считаем по полю `reminder_hour_changed_at`. Поле добавили в ту же миграцию и дописали в раздел 3 |
